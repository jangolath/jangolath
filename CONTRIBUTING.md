# Contributing

This repository holds my GitHub profile README, so outside changes are rare, but fixes are welcome.

- **Typos, broken links, outdated facts:** open an issue or a pull request against `main`.
- **Pull requests:** keep them small and focused, describe what changed and why, and use a clear commit message
  (imperative mood, e.g. "Fix broken link to radar").
- **Review:** `main` is protected. Every change lands through a pull request that I review; direct pushes are disabled.
- **Conduct:** be respectful and constructive.

For contributions to my projects, see the CONTRIBUTING guide in each project's repository.
